# ✨ Premium Todo App

A beautiful, lightweight, and fully functional Todo application built with **vanilla HTML, CSS, and JavaScript**. Features a premium light theme, smooth animations, and persistent storage — no frameworks, no dependencies.

## 🚀 Features

- ✅ **Add tasks** — quickly create new todos
- ✏️ **Edit tasks** — update any todo inline
- 🗑️ **Delete tasks** — remove todos you no longer need
- ✔️ **Mark as complete** — toggle done state with visual feedback
- 💾 **LocalStorage persistence** — tasks survive page refreshes
- ⌨️ **Keyboard support** — press `Enter` to add or update
- 🎨 **Premium light theme** — soft gradients, glassmorphism, smooth animations
- 📱 **Responsive design** — works beautifully on mobile and desktop
- ♿ **Accessible** — focus states, reduced-motion support, semantic markup
